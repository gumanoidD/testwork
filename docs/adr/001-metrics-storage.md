# 1. Збереження метрик та парсинг Telegram Web View

## Статус
Прийнято

## Контекст
Необхідно збирати публічні пости з `t.me/s/<channel>` без використання офіційного
API / Bot API, підтримувати ідемпотентність та відстежувати динаміку переглядів.

## Рішення
1. **Парсинг HTML**: використано `BeautifulSoup4` для розбору веб-сторінок `t.me/s/`.
2. **Збереження даних**:
   - `posts`: зберігає унікальний пост (`channel` + `message_id`).
   - `post_metrics`: записує точний зріз переглядів (`views`) та час фіксації
     (`fetched_at`) під час кожного запуску скрапера.
3. **Ідемпотентність**: забезпечується через `UniqueConstraint("channel", "message_id")`.

## Наслідки
- Можливість будувати графіки зміни переглядів з часом.
- Відсутність дублікатів постів при повторних запусках `collect`.
- Таблиця `post_metrics` росте необмежено — прийнятно для обсягу тестового завдання,
  але при довгій експлуатації знадобиться ретеншн/агрегація старих точок.
